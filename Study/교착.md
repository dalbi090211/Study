# Race Tracing(경쟁 상태)

공유 자원을 여러 스레드가 사용하여 실행 순서에 따라 결과가 달라지는 현상 

```cpp
#include <thread>

int counter = 0;

auto work = [](){
    for(int i = 0; i < 100; i++){
        counter++;
        cout << "i : " << i << " counter : " << counter << endl;
    }
}

thread t1(work);
thread t2(work);

t1.join();
t2.join();
```

마지막엔 counter = 200이 되고, 
```cpp
i : 8i : 11 counter : 21
 counter : 21
```
이런 식으로 출력이 겹쳐서 나옴

# Dead lock(교착 상태)

같은 자원을 두고 서로 상대방을 기다리느라 아무것도 못하는 상황
```cpp
#include <mutex>
#include <thread>

mutex m1, m2;

auto work1 = [](){
    m1.lock();

    this_thread::sleep_for(chrono::seconds(1));

    m2.lock();
}

auto work2 = [](){
    m2.lock();

    this_thread::sleep_for(chrono::seconds(1));

    m1.lock();
}

thread t1(work1);
thread t2(work2);

t1.join();
t2.join();
```

t1은 m2를, t2는 m1의 반환을 기다리지만 t1이 m1을 들고, t2가 m2를 들고 있어서 서로 대기하는 교착상태에 빠짐

# 교착의 4가지 조건
교착 상태는 4가지 조건이 모두 만족되는 경우 발생할 가능성이 있음
하나라도 만족하지 않으면 발생하지 않음

## 상호 배제
여러 스레드가 하나의 자원에 접근할 때 한 번에 한 개의 스레드 만이 공유 자원을 사용할 수 있다.
```cpp
#include <iostream>
#include <thread>
#include <mutex>

using namespace std;

int counter = 0;

mutex m1;

auto work = []()
{
    m1.lock();
    for (int i = 0; i < 100; i++)
    {
        cout << "i : " << i << " counter : " << counter << endl;
        counter++;
    }
    m1.unlock();
};

int main()
{
    thread t1(work);
    thread t2(work);

    t1.join();
    t2.join();
}
```
앞서 설명한 race tracing(경쟁 상태)에서는 하나의 자원에 대한 동시접근이 가능했음. 따라서 결과가 비정상적이고, 예측하기 힘듬. 이를 해결하기 위해 `mutex`를 통해 자원에 접근할 때 잠금. 똥쌀 때 문을 잠구듯이 열쇠를 가져가고, 다 싸고 나올 때 열쇠를 돌려줌.

`semaphore`는 mutex가 사용하던 화장실 칸 수를 늘림.

```cpp
#include <iostream>
#include <thread>
#include <semaphore>

using namespace std;

int counter = 0;

counting_semaphore<3> sem(3); // c++20 부터 지원

auto work = [](int trial)
{
    auto start = chrono::steady_clock::now();

    sem.acquire();
    for (int i = 0; i < 100; i++)
    {
        counter++;
    }
    sem.release();

    auto end = chrono::steady_clock::now();

    auto duration = chrono::duration_cast<chrono::microseconds>(end - start);
    cout << trial << " trial : " << duration.count() << endl;
};

int main()
{
    thread t1(work, 1);
    thread t2(work, 2);
    thread t3(work, 3);
    thread t4(work, 4);
    thread t5(work, 5);
    thread t6(work, 6);

    t1.join();
    t2.join();
    t3.join();
    t4.join();
    t5.join();
    t6.join();
}
```
둘 다 release나 unlock 안해주면 영원히 못쓸 수 있음

## 점유와 대기

스레드가 하나 이상의 자원을 점유한 상태에서 다른 자원을 얻기 위해 기다리는 것. 해제하는 방법은 간단하다. 다른 자원을 기다릴 때 기존 자원을 계속 점유하지 않으면 된다.

## 비선점

다른 스레드가 점유하고 있는 자원을 강제로 빼앗을 수 없음.
