# 참조

`&`는 원본의 참조를 제공함
참조를 통해 원본의 값을 변경할 수 있음

```cpp
int a = 10;
int& b = a;
int c = a;

a += 10;

cout << b << " " << c << endl;  //20 10
```
일반적으로 대입 연산자 `=`는 복사를 진행. `&`를 붙여야 참조를 먹을 수 있음

# 람다식

```cpp
auto func = []() {
    cout << "lamda" << endl;
};

func();
```

함수 내에 넣는 지역 함수? 같은 느낌으로 사용. 하나의 함수 내에서만 반복되는 기능인 경우 주로 사용

`[]` 안에 `=`이 들어가면 값을 캡쳐할 수 있음

```cpp
int a = 10;
auto func = [=]() {
    //a += 10; //컴파일 오류 발생, 캡쳐를 위한 값을 변경시킬 수는 없음
    cout << a + 10 << endl;
};

func();
```

`[]` 안에 `&`이 들어가면 값을 참조할 수 있음

```cpp
int a = 10;
auto func = [&]() {
    a += 10;    //참조로 가져왔기에 변경 가능
    cout << a << endl;
};

func();     //20 출력
func();     //30 출력
```

`()`안에 들어간 변수는 일반 함수처럼 매개변수로 사용가능. `[=]`이더라도 `int& num`과 같이 받아서 값을 참조가능

``` cpp
int a = 10;

auto func = [=](int& num1) {
    num1 += 10;
}

func(a);
cout << a << endl;  //20
```

# const

`const` 는 단어 뜻 그대로 제한함. 포인터 에 붙이면 주소의 변경을 제한하고, 변수에 붙이면 값의 변경을 제한함

``` cpp
const int length = 10;

// a = 20;  //컴파일 오류
```

``` cpp
int a = 10;

//주소 변경 제한, const가 포인터(*) 앞에 있는 경우
const int* intPtr1 = &a;
int const * intPtr2 = &a;

//값 변경 제한, const가 포인터 뒤에 있는 경우
int* const intPtr3 = &a;
```
