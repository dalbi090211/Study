## 리지드 바디
리지드 바디란 `Unity`에서 물리 연산을 수행하는 컴포넌트이다. `Body Type`을 `Kinematic`, `Static`, `Dynamic` 3가지 타입으로 설정할 수 있음.

`Dynamic`을 사용하면 정확한 물리 연산을 제공한다. 하지만 정확한 물리보다는 유저가 느끼기에 좋은 조작감을 제공하는 물리 반응을 위해 `Kinematic`을 선택해 커스텀으로 물리 반응을 구현할 수 있음.

코요테 타임, 점프 버퍼링 등 실제 정확한 판정보다는 유저의 좋은 조작감을 위한 처리가 존재함.

## 가속도
`AnimationCurve`를 통해 연속적인 비선형 `float`값을 받아올 수 있음. `Curve.Evaluate(float time)` 을 통해 시간에 맞는 값을 받아온 후, `Time.fixedDeltaTime`을 곱한 값을 `Velocity`에 더해 구현할 수 있음.



## 물리 연산 지연
`FixedUpdate`는 물리 연산 업데이트, `Update`는 기본 업데이트로 사용됨. `Update`는 프레임을 기반으로 움직이고, `FixedUpdate`는 1초에 50회를 목표로 움직임. 

이때 지연된 시간이 존재한다면 `FixedUpdate`는 `Time.fixedDeltaTime`에 맞춰 다음에 더 많이 `FixedUpdate`를 실시함. `Update`는 `Time.DeltaTime`을 늘려 지연된 시간만큼 더 큰 값을 사용함.

지연 때문에 더 심한 지연이 발생하는 문제를 방지하기 위해 실제 프레임 경과 시간이 `Time.maximumDeltaTime`보다 크다면 더이상 조정하지 않고, 일정 시간을 포기함.

`Time.deltaTime`은 `FixedUpdate`에서는 `FixedUpdate`의 시간 초를, `Update`에서는 이전 프레임 간의 지연 시간을 반환하지만 `Time.fixedDeltaTime`은 항상 `FixedUpdate`의 시간 초를 반환함. 따라서 `Update`에서 `Time.fixedDeltaTime`을 사용한다면 프레임 지연이 발생했을 때 이동속도가 감소하는 문제가 발생할 수 있음.


## 충돌 판정

하위 오브젝트로 `Collider2D`를 단 오브젝트를 바닥이라고 판정할 부분에 놓고, `OnTriggerEnter2D`를 이용하거나, 자신의 Position을 기반으로 매 Tick마다 Collider의 이동 시 발생할 충돌을 계산하는 방법이 존재한다. 이때 오브젝트의 법선 벡터를 이용해 방향을 구하고, 바닥인지 벽인지 판정할 수 있다.

`capsule.Cast()`를 통해 기존 충돌체의 이동 시 발생할 충돌을 계산할 수 있고, `ContactFilter2D`를 이용해 판정할 오브젝트의 `Layer`를 지정할 수 있다.
